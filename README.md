# **HR Workforce Analytics**
An HR data analytics project focused on understanding employee performance, satisfaction, compensation, promotion, training, overtime, and attrition using Python, Pandas, SQL, and SQLite.

# **🎯 Objective**
The goal of this project is to demonstrate how SQL can be used to analyze HR data, identify workforce trends, and support data-driven business decisions.

# **📊 Project Overview**

This project analyzes a dataset of 1,000 employees to identify workforce patterns and generate actionable HR insights.

## Key Analysis

- Workforce and department distribution
- Salary and compensation analysis
- Employee performance analysis
- Employee satisfaction analysis
- Overtime and workload analysis
- Training and performance analysis
- Promotion analysis
- Attrition analysis
- Manager and state-level workforce analysis
- Employee segmentation
- Department performance scorecard

# **🛠️ Tools & Technologies**

- Python
- Pandas
- SQL
- SQLite
- Jupyter Notebook

# **📌 Key Findings**

- Overall employee attrition rate: 9.8%
- Overall promotion rate: 16.9%
- Average salary: ₹728,523
- Sales has the highest attrition rate at 12.3%
- IT has the lowest attrition rate at 7.14%
- Purchase has the highest average performance rating at 3.23/5
- Sales has the lowest average satisfaction score at 5.08/10
- High-performing employees showed 0% observed attrition in this dataset
